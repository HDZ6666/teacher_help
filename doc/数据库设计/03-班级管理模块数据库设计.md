## 1. 模块概述

### 1.1 业务场景

班级管理模块负责管理教育培训机构的班级信息,包括:

- **班课管理**: 一对多的班级课程管理
- **一对一管理**: 一对一辅导课程管理
- **学员分配**: 学员加入班级、退出班级
- **教师分配**: 主讲教师、助教分配
- **班级状态**: 招生中、已满员、已结课等状态管理

### 1.2 核心功能

1. **班级创建**: 创建系统班型或自建班型
2. **学员管理**: 添加学员、移除学员、查看学员列表
3. **教师管理**: 分配主讲教师和助教
4. **班级点名**: 班级考勤管理
5. **班级详情**: 查看班级信息、学员列表、课程安排

## 2. 数据表设计

### 2.1 班级基本信息表 (ast_class)

#### 2.1.1 表基本信息

| 项目 | 内容 |
|------|------|
| 表名 | `ast_class` |
| 说明 | 存储班级的基本信息 |
| 引擎 | InnoDB |
| 字符集 | utf8mb4 |

#### 2.1.2 字段列表

| 字段名 | 类型 | 长度 | 必填 | 默认值 | 说明 | 字段分类 |
|--------|------|------|------|--------|------|---------|
| `id` | BIGINT | - | 是 | AUTO | 主键ID | 系统字段 |
| `class_no` | VARCHAR | 50 | 否 | NULL | 班级编号 | 自有字段 |
| `class_name` | VARCHAR | 100 | 是 | - | 班级名称 | 自有字段 |
| `class_type` | VARCHAR | 20 | 是 | - | 班级类型 | 字典字段(ast_class_type) |
| `course_id` | BIGINT | - | 是 | - | 课程ID | 外键字段(ast_course) |
| `course_name` | VARCHAR | 100 | 是 | - | 课程名称(冗余) | 自有字段 |
| `course_type` | TINYINT | 1 | 是 | - | 课程类型(冗余) | 字典字段(ast_course_type) |
| `grade` | VARCHAR | 20 | 否 | NULL | 年级 | 字典字段(ast_grade) |
| `subject` | VARCHAR | 50 | 否 | NULL | 科目 | 字典字段(ast_subject) |
| `semester` | VARCHAR | 20 | 否 | NULL | 学期 | 字典字段(ast_semester) |
| `teacher_id` | BIGINT | - | 否 | NULL | 主讲教师ID | 外键字段(sys_user) |
| `teacher_name` | VARCHAR | 50 | 否 | NULL | 主讲教师姓名 | 自有字段 |
| `assistant_id` | BIGINT | - | 否 | NULL | 助教ID | 外键字段(sys_user) |
| `assistant_name` | VARCHAR | 50 | 否 | NULL | 助教姓名 | 自有字段 |
| `classroom` | VARCHAR | 50 | 否 | NULL | 教室 | 自有字段 |
| `max_students` | INT | - | 否 | 0 | 最大学员数 | 自有字段 |
| `current_students` | INT | - | 否 | 0 | 当前学员数 | 自有字段 |
| `enroll_status` | TINYINT | 1 | 否 | 1 | 招生状态 | 字典字段(ast_enroll_status) |
| `start_date` | DATE | - | 否 | NULL | 开课日期 | 自有字段 |
| `end_date` | DATE | - | 否 | NULL | 结课日期 | 自有字段 |
| `status` | TINYINT | 1 | 否 | 1 | 启用状态 | 字典字段(sys_normal_disable) |
| `create_by` | VARCHAR | 64 | 否 | '' | 创建者 | 系统字段 |
| `create_time` | DATETIME | - | 否 | CURRENT | 创建时间 | 系统字段 |
| `update_by` | VARCHAR | 64 | 否 | '' | 更新者 | 系统字段 |
| `update_time` | DATETIME | - | 否 | CURRENT | 更新时间 | 系统字段 |
| `remark` | VARCHAR | 500 | 否 | NULL | 备注 | 系统字段 |
| `del_flag` | TINYINT | 1 | 否 | 0 | 删除标志 | 系统字段 |

#### 2.1.3 索引设计

| 索引名 | 索引类型 | 字段 | 说明 |
|--------|---------|------|------|
| PRIMARY | 主键索引 | id | 主键 |
| uk_class_no | 唯一索引 | class_no | 班级编号唯一 |
| idx_class_name | 普通索引 | class_name | 班级名称查询 |
| idx_course_id | 普通索引 | course_id | 课程ID查询 |
| idx_teacher_id | 普通索引 | teacher_id | 教师ID查询 |
| idx_enroll_status | 普通索引 | enroll_status | 招生状态查询 |
| idx_status | 普通索引 | status | 启用状态查询 |

#### 2.1.4 表关联关系

- **关联课程表**: 多对一关系,一个班级对应一个课程
- **关联学员表**: 多对多关系,通过班级学员关联表关联
- **关联教师表**: 多对一关系,一个班级有一个主讲教师和一个助教
- **关联排课表**: 一对多关系,一个班级可以有多条排课记录
