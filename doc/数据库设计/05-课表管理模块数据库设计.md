## 1. 模块概述

### 1.1 业务场景

课表管理模块负责管理教育培训机构的排课和约课,包括:

- **排课管理**: 为班级安排上课时间、教室、教师
- **约课管理**: 学员预约一对一课程
- **课表展示**: 多维度课表展示(时间/老师/教室/班级)
- **冲突检测**: 排课时间冲突、教室冲突、教师冲突检测
- **循环排课**: 支持按周循环排课

### 1.2 核心功能

1. **排课**: 单次排课、批量排课、循环排课
2. **约课**: 学员预约一对一课程
3. **课表查询**: 按时间、教师、教室、班级查询课表
4. **冲突检测**: 自动检测排课冲突
5. **课程调整**: 调课、停课、补课

## 2. 数据表设计

### 2.1 排课记录表 (ast_schedule)

#### 2.1.1 表基本信息

| 项目 | 内容 |
|------|------|
| 表名 | `ast_schedule` |
| 说明 | 存储课程的排课信息 |
| 引擎 | InnoDB |
| 字符集 | utf8mb4 |

#### 2.1.2 字段列表

| 字段名 | 类型 | 长度 | 必填 | 默认值 | 说明 | 字段分类 |
|--------|------|------|------|--------|------|---------|
| `id` | BIGINT | - | 是 | AUTO | 主键ID | 系统字段 |
| `schedule_no` | VARCHAR | 50 | 否 | NULL | 排课编号 | 自有字段 |
| `class_id` | BIGINT | - | 是 | - | 班级ID | 外键字段(ast_class) |
| `class_name` | VARCHAR | 100 | 是 | - | 班级名称(冗余) | 自有字段 |
| `course_id` | BIGINT | - | 是 | - | 课程ID | 外键字段(ast_course) |
| `course_name` | VARCHAR | 100 | 是 | - | 课程名称(冗余) | 自有字段 |
| `course_type` | TINYINT | 1 | 是 | - | 课程类型(冗余) | 字典字段(ast_course_type) |
| `teacher_id` | BIGINT | - | 否 | NULL | 教师ID | 外键字段(sys_user) |
| `teacher_name` | VARCHAR | 50 | 否 | NULL | 教师姓名 | 自有字段 |
| `classroom` | VARCHAR | 50 | 否 | NULL | 教室 | 自有字段 |
| `schedule_date` | DATE | - | 是 | - | 上课日期 | 自有字段 |
| `start_time` | TIME | - | 是 | - | 开始时间 | 自有字段 |
| `end_time` | TIME | - | 是 | - | 结束时间 | 自有字段 |
| `duration` | INT | - | 否 | 0 | 课程时长(分钟) | 自有字段 |
| `deduct_count` | DECIMAL | 5,2 | 否 | 1.00 | 扣课时数 | 自有字段 |
| `is_recurring` | TINYINT | 1 | 否 | 0 | 是否循环排课 | 自有字段 |
| `recurring_rule` | VARCHAR | 200 | 否 | NULL | 循环规则(JSON格式) | 自有字段 |
| `parent_schedule_id` | BIGINT | - | 否 | NULL | 父排课ID(循环排课的父记录) | 外键字段(ast_schedule) |
| `schedule_status` | TINYINT | 1 | 否 | 1 | 排课状态(1=正常,2=已取消,3=已调课) | 自有字段 |
| `cancel_reason` | VARCHAR | 200 | 否 | NULL | 取消原因 | 自有字段 |
| `create_by` | VARCHAR | 64 | 否 | '' | 创建者 | 系统字段 |
| `create_time` | DATETIME | - | 否 | CURRENT | 创建时间 | 系统字段 |
| `update_by` | VARCHAR | 64 | 否 | '' | 更新者 | 系统字段 |
| `update_time` | DATETIME | - | 否 | CURRENT | 更新时间 | 系统字段 |
| `remark` | VARCHAR | 500 | 否 | NULL | 备注 | 系统字段 |
| `del_flag` | TINYINT | 1 | 否 | 0 | 删除标志 | 系统字段 |

#### 2.1.3 索引设计

| 索引名 | 索引类型 | 字段 | 说明 |
|--------|---------|------|------|
| PRIMARY | 主键索引 | id | 主键 |
| uk_schedule_no | 唯一索引 | schedule_no | 排课编号唯一 |
| idx_class_id | 普通索引 | class_id | 班级ID查询 |
| idx_course_id | 普通索引 | course_id | 课程ID查询 |
| idx_teacher_id | 普通索引 | teacher_id | 教师ID查询 |
| idx_classroom | 普通索引 | classroom | 教室查询 |
| idx_schedule_date | 普通索引 | schedule_date | 上课日期查询 |
| idx_schedule_status | 普通索引 | schedule_status | 排课状态查询 |
| idx_date_time | 普通索引 | schedule_date, start_time | 日期时间联合查询 |

#### 2.1.4 表关联关系

- **关联班级表**: 多对一关系,一条排课记录对应一个班级
- **关联课程表**: 多对一关系,一条排课记录对应一个课程
- **关联教师表**: 多对一关系,一条排课记录对应一个教师
- **关联上课记录表**: 一对一关系,排课后生成上课记录
- **自关联**: 循环排课时,子记录关联父记录
