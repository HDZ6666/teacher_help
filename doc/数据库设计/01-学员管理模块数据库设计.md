## 1. 模块概述

### 1.1 设计原则说明

本模块严格遵循**若依(RuoYi)框架的数据库设计规范**:

1. **审计字段规范**:
   - ✅ 使用 `create_by` 和 `update_by` 存储用户名(VARCHAR类型)
   - ❌ 不使用 `creator_id` 和 `creator_name` 等冗余字段
   - 📌 `create_by` 字段本身就是用户名,不需要额外的name字段

2. **外键字段规范**:
   - ✅ 外键字段只存储ID,不冗余关联对象的名称
   - ✅ 示例: `follower_id` 和 `advisor_id` 只存储用户ID
   - ❌ 不使用 `follower_name` 和 `advisor_name` 等冗余字段
   - 📌 查询时通过 JOIN sys_user 表获取用户姓名

3. **核心业务字段规范**:
   - ✅ 核心业务属性(如 `phone`, `phone_relation`)直接存储在主表
   - ✅ 这是业务必需字段,不是冗余设计

### 1.2 业务场景

学员管理模块是助教管理系统的核心模块之一,负责管理学员的完整生命周期,包括:

- **学员档案管理**: 学员基本信息、联系方式、家庭住址等
- **学员报名管理**: 课程报名、课时购买、报名状态跟踪
- **课时账户管理**: 课时余额、课时消费、课时赠送、课时退转
- **学员标签管理**: 学员分类标签、个性化标记
- **学员跟进管理**: 跟进人、学管师分配

### 1.2 核心功能

1. **在读学员管理**: 查询、新增、编辑、删除学员档案
2. **报读情况管理**: 查看学员报名课程、课时余额、消费记录
3. **学员报名/续费**: 选择课程、课包、物品、费用进行报名
4. **学员分配**: 分配跟进人、学管师
5. **学员标签**: 自定义标签管理
6. **报名订单管理**: 管理学员报名订单及订单明细
7. **课时账户管理**: 管理学员课时余额、消耗记录、有效期

- **关联订单明细表**: 多对一关系,通过 `order_item_id` 关联 `ast_enrollment_order_item` 表

#### 2.4.5 业务说明

**账户创建时机**:
- 当订单支付成功后,系统自动为每个课程类型的订单明细创建课时账户
- 一个订单明细对应一个课时账户

**账户状态说明**:
- `1=正常`: 账户有余额且未过期
- `2=已用完`: 剩余数量为0
- `3=已过期`: 超过有效期
- `4=已退费`: 订单退款后的状态

**课时消耗规则**:
- 每次上课点名时,扣除对应的课时数量
- 同时扣除对应的金额 (consumed_amount = consumed_count × 单价)
- 更新剩余数量和剩余金额

**有效期管理**:
- 按课时课程: 使用 `expire_date` + `validity_type`
- 按月/按天课程: 使用 `start_date` + `end_date`

#### 2.6.4 表关联关系

- **关联学员表**: 多对一关系,通过 `student_id` 关联 `ast_student` 表
- **关联订单主表**: 多对一关系,通过 `order_id` 关联 `ast_enrollment_order` 表
- **关联课程表**: 当 `item_type='course'` 时,通过 `item_id` 关联 `ast_course` 表
- **关联课程定价表**: 当 `item_type='course'` 时,通过 `spec_id` 关联 `ast_course_price` 表
- **关联物品表**: 当 `item_type='item'` 时,通过 `item_id` 关联 `ast_item` 表
- **关联物品SKU表**: 当 `item_type='item'` 时,通过 `spec_id` 关联 `ast_item_sku` 表
- **关联费用表**: 当 `item_type='fee'` 时,通过 `item_id` 关联 `ast_fee_item` 表
- **关联班级表**: 多对一关系,通过 `class_id` 关联 `ast_class` 表
- **关联课时账户表**: 一对一关系,订单支付成功后为课程类型的明细创建课时账户

#### 2.6.5 业务说明

**项目类型说明**:
- `course`: 课程项目,关联 `ast_course` 表
- `item`: 物品项目,关联 `ast_item` 表和 `ast_item_sku` 表
- `fee`: 费用项目,关联 `ast_fee_item` 表
- `card`: 卡项项目(预留,后续扩展)

**规格/定价ID (spec_id) 说明**:
- 当 `item_type='course'` 时: `spec_id` 关联 `ast_course_price.id` (课程定价标准)
- 当 `item_type='item'` 时: `spec_id` 关联 `ast_item_sku.id` (物品SKU)
- 当 `item_type='fee'` 时: `spec_id` 为 `NULL` (费用无规格)
- 当 `item_type='card'` 时: `spec_id` 关联 `ast_card_sku.id` (卡项规格,预留)

**数据来源说明**:
- 订单明细表是学员报读信息的唯一数据源
- 通过 `item_type='course'` 过滤可获取所有课程报读记录
- 通过 `student_id` 可查询学员的所有报读课程
- 订单支付成功后,系统自动为课程类型的明细创建课时账户

**赠送单位规则**:
- 按课时收费: `gift_unit` 只能是 "课时"
- 按月收费: `gift_unit` 可以是 "月" 或 "天"
- 按天收费: `gift_unit` 只能是 "天"
- 物品/费用: `gift_unit` 与 `unit` 保持一致

**优惠类型说明**:
- `percent`: 折扣优惠,`discount_value` 为百分比(如80表示8折)
- `amount`: 直减优惠,`discount_value` 为直减金额

**有效期设计说明**:
- **按课时课程**: 使用 `validity_type` (生效方式),有效期在课时账户表中管理
  - `validity_type='not_set'`: 不设置有效期
  - `validity_type='immediate'`: 立即生效
  - `validity_type='first_attendance'`: 第一次点名生效
- **按月/按天课程**: 使用 `start_date` 和 `end_date` (上课时间段)
  - 例如: 2025-01-01 ~ 2025-03-31
  - `validity_type` 为 NULL

### 4.1 示例1: 按课时收费 + 折扣优惠

**业务场景**: 学员购买数学提高班,选择24课时套餐,享受8折优惠,赠送2课时

```sql

    unit_price, quantity, unit, total_price,
    gift_quantity, gift_unit,
    discount_type, discount_value, discount_amount, subtotal,
    start_date, end_date, expire_date, validity_type,
    class_id, leave_exempt_count, sort_order
) VALUES (
    1001,                           -- order_id
    'course',                       -- item_type
    5,                              -- item_id (数学提高班)
    '数学提高班',                    -- item_name
    12,                             -- spec_id (关联 ast_course_price.id=12)
    '24课时套餐(4800元)',            -- spec_name
    'lesson',                       -- charge_type
    200.00,                         -- unit_price (4800/24)
    24,                             -- quantity
    '课时',                          -- unit
    4800.00,                        -- total_price
    2,                              -- gift_quantity
    '课时',                          -- gift_unit
    'percent',                      -- discount_type (折扣)
    80.00,                          -- discount_value (8折)
    960.00,                         -- discount_amount (4800×0.2=960)
    3840.00,                        -- subtotal (4800-960=3840)
    NULL,                           -- start_date (按课时不使用)
```
