# 物品费用模块总结报告

## 模块定位

物品费用模块负责维护报名和套餐中可售的实物物品、杂费项目，以及物品库存的出入库流水。它连接销售订单、套餐配置、库存变动和财务支付，是教务商品和库存管理的基础模块。

## 能创建什么

- 物品：可新增物品名称、图片、规格、售价、库存预警数和绑定课程。
- 多规格物品：支持新增规格名和规格值，如颜色、尺码等，并为规格组合生成库存项。
- 费用项目：可新增除课程和物品外的收费项目，设置费用名称、售卖单价和绑定课程。
- 采购入库单：可新建采购，填写采购日期、采购单价、采购数量、采购总价和支付信息。
- 领用/领退/盘点记录：可创建领用、退回和盘点操作，形成库存变动流水。
- 采购导入：支持通过模板导入物品采购订单。

## 能编辑和管理什么

- 物品列表：筛选物品、查看剩余库存、售价、规格、预警状态、启用状态和线上售卖状态。
- 物品资料：编辑物品名称、图片、规格、售价、库存预警和绑定课程。
- 库存流水：按出入库日期、业务类型、角色类型、角色姓名等筛选出入库记录，查看关联订单。
- 出入库详情：查看业务类型、操作时间、物品名称、规格、购买/领用数量、经办人和关联订单。
- 费用列表：启用/停用费用、设置线上售卖、编辑或删除费用。

## 主要流程

1. 物品建档流程：新增物品，设置规格、售价、库存预警和绑定课程，启用后可在报名或套餐中选择。
2. 库存入库流程：新建采购或导入采购单，填写数量和付款信息，形成入库流水。
3. 库存出库流程：学员报名购买物品后，订单关联库存出库；也可手工领用、领退或盘点。
4. 费用配置流程：创建费用项目，绑定课程后可加入套餐或报名订单。
5. 查询对账流程：通过出入库记录查看物品来源、经办人、关联订单和库存变化。

## 模块作用

- 管理课程之外的实物商品和杂费项目，支撑更完整的报名收费场景。
- 通过采购、销售、领用、退货、盘点记录维持库存账，便于库存预警和对账。
- 让套餐可以组合课程、物品、费用，形成多项目销售方案。

## 与其他模块的联动

- 学员管理：学员报名可选择物品和费用，生成消费记录、收据和出库记录。
- 课程管理：物品和费用可绑定课程，也可被加入课程套餐。
- 财务/订单：采购、销售、付款和关联订单影响财务记录。
- 套餐管理：套餐明细可选择物品和费用，价格、数量和赠送规则来自本模块。
- 在线售卖：物品和费用的线上售卖状态影响线上展示。

## 关注点

物品存在负库存截图场景，说明系统允许或曾出现库存不足销售/出库。建议明确是否允许负库存，并对采购、销售、领用、盘点等库存变动保留完整审计，避免库存和订单金额无法对齐。
