- 数据库 root 账号口令（公网数据库地址和端口）
- Redis 口令（公网 Redis 地址和端口）
- JWT 秘钥（RuoYi-FastAPI 模板默认值）

3. 如需从历史中彻底清除，可在所有协作者同意后用 `git filter-repo` 清理并强制推送（轮换凭据仍然是必须的）。

## 部署/开发环境变化

- 复制 `teacher_help_service/.env.example` 为 `.env.dev` / `.env.prod` 并填写真实配置；这两个文件已被 `.gitignore` 忽略。
- `APP_ENV=prod` 时若 `JWT_SECRET_KEY` 未设置或仍为占位值，服务拒绝启动；开发环境只给出警告。
- `config/env.py` 默认 `DB_ECHO=false`，数据库口令默认空。
- 新库初始化顺序：`sql/ruoyi-fastapi.sql` → `sql/teacher_help_teach_tables.sql` → `doc/数据库设计/SQL/04-物品费用管理模块建表语句.sql` → `sql/teacher_help_menu.sql`。
- 已有库：执行 `sql/teacher_help_menu.sql`；按 `sql/teacher_help_teach_tables.sql` 末尾说明先检查重复点名，再给 `teach_class_attendance` 加唯一约束 `uk_class_attendance_event`。
- 非超管角色需要在“角色管理”中勾选按钮权限（菜单ID 5000-5999，目录默认隐藏）。上传/下载新增权限 `common:file:upload`、`common:file:download`，普通角色需要分配后才能使用富文本图片上传、文件上传和导出下载。
