# 老师帮移动端 Stitch 提示词索引

本目录把老师帮移动端 App 原型提示词拆成多份小 Markdown 文件，方便在 Google Stitch 中分批生成移动端原型图。

## 推荐复制顺序

1. 先复制 `00-全局风格与通用约束.md`，让 Stitch 记住产品定位、UI 风格、颜色、组件、底部 Tab 和通用交互。
2. 再复制 `01` 到 `06`，生成移动端首版核心 App：登录、今日、课表、点名、学员、AI 错题本、我的。每个模块文件开头已经带有“请基于刚才的全局风格...”前置句，可以整份复制。
3. 如果需要补全 PC 端管理能力，再复制 `07` 到 `12`，逐个生成班级、课程、老师、物品费用、会员卡、场地管理。每个模块同样可以整份复制。
4. 每次只生成一个模块或一个关键流程，不要一次粘贴全部文件。
5. 每次追问修改时补一句：“保持上一版颜色、字号、卡片、底部 Tab 和组件风格不变。”

## Stitch 提示词最佳实践

结合 Google AI Developers Forum 的 Stitch Prompt Guide 和 Google 对 Stitch 的官方介绍，复杂 App 更适合使用“全局风格 + 单模块 + 单轮细化”的方式，而不是一次性要求生成全部页面。

每次提示词建议包含：

- 产品背景：这个 App 是给谁用的。
- 本次目标：只生成哪个模块或哪个流程。
- 页面结构：顶部、列表、卡片、底部按钮、弹层分别是什么。
- 按钮功能：每个按钮点击后代表什么动作。
- 视觉约束：颜色、圆角、卡片、Tab、状态标签。
- 禁止内容：不要 PC 后台、不要大表格、不要营销页、不要换风格。
- 输出要求：移动端 375px 宽，高保真 UI，可继续导出到 Figma。

## 可复用的 Stitch 开场模板

```text
请为“老师帮”App 生成【模块名】移动端高保真原型，保持我之前给你的全局风格。

产品背景：老师帮是培训机构老师和校区管理者使用的移动办公 App，核心目标是快速查看今日课程、快速点名、快速排课调课、快速查看学员、快速上传错题并让 AI 解析。

本次只生成：【模块名 / 页面名 / 流程名】。

必须保持：移动端 375px 宽，背景 #f4f6f5，白色卡片，主按钮 #1f7159，底部 Tab 为“今日、课表、学员、错题本、我的”，整体风格专业、清爽、信息密度适中。

页面结构：……
按钮与功能：……
状态与弹窗：……

不要生成：PC 后台菜单、大表格、面包屑、营销页、夸张插画、紫蓝渐变，也不要更换已有 UI 风格。
```
