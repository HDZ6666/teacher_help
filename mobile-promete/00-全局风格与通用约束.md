# 老师帮移动端 App 全局风格与通用约束

把本文件作为每次生成 Stitch 原型前的基础上下文。后续每个模块只补充该模块的页面和按钮即可。

## 产品定位

老师帮移动端 App 是培训机构老师和校区管理者的移动办公工具，不是 PC 管理后台的缩小版。移动端第一目标是让老师在手机上快速完成高频动作：

- 快速查看今天要上的课。
- 快速点名，减少课前等待。
- 快速排课、调课，处理临时安排。
- 快速查看学员信息、请假和联系家长。
- 快速上传错题图片，由 AI 识别题目并生成讲解。

## 技术栈和实现约束

移动端原型需要贴近当前 uni-app 项目的技术和 UI 风格：

- 技术栈：uni-app + Vue 3 + TypeScript + Pinia + UnoCSS。
- 组件倾向：uni-icons、sard-uniapp、wot-design-uni、z-paging。
- 原型组件应使用移动端常见控件：顶部导航、底部 Tab、卡片、列表、标签、底部弹层、搜索框、日期条、分段控制器、单选、多选、表单项、上传区。
- 不要设计成 Element Plus PC 后台风格，不要出现密集表格、复杂树表格、PC 左侧菜单。
- 不引入新的视觉体系，不使用营销页、夸张插画首页、网页式大 Hero。

## 页面尺寸

- 以移动端竖屏为准，建议画布宽度 375px，高度 812px。
- 内容区域左右留白约 14px，对应 uni-app 28rpx。
- 底部 Tab 固定在屏幕底部。
- 主要操作按钮放在底部安全区上方，方便单手点击。

## 颜色

必须保持当前 uni-app 已有绿色系工作台风格，但避免全屏单一绿色。用白色卡片、浅灰背景和状态色做层次。

- 页面背景：`#f4f6f5`
- 主文字：`#1f2d33`
- 深色重点卡片：`#193f36`
- 主按钮：`#1f7159`
- 辅助绿色：`#2a9d73`
- 链接绿色：`#1d8b69`
- 底部 Tab 选中：`#018d71`
- 卡片背景：`#ffffff`
- 卡片边框：`#e7ece9`
- 次级文字：`#64737b`
- 弱提示文字：`#718088`、`#74828a`、`#839099`
- 成功状态：文字 `#227253`，背景 `#e9f6ef`
- 警告状态：文字 `#8a671b`，背景 `#fff5d8`
- 危险状态：文字 `#9a3b33`，背景 `#ffeceb`
- 已完成/中性状态：文字 `#5d6a70`，背景 `#eef2f0`

## 字体和层级

- 字体使用系统无衬线字体。
- 页面主标题 20-22px，字重 600。
- 卡片标题 16-18px，字重 600。
- 正文 14-15px。
- 辅助信息 12-13px。
- 数字统计可以使用 24-30px，但只用于关键数字。
- 不使用负字距，不用过大的网页标题。

## 圆角、间距和组件尺寸

- 普通卡片圆角 14-16rpx，视觉上约 7-8px。
- 深色重点卡片圆角 18rpx，视觉上约 9px。
- 主按钮高度 44-46px。
- 图标按钮保持 40-44px 可点击区域。
- 标签和状态 chip 使用胶囊圆角 999rpx。
- 列表项高度稳定，不因标签数量产生明显跳动。
- 卡片之间垂直间距 10-14px。

## 底部 Tab

全局固定 5 个 Tab：

1. 今日：默认首页，老师每天打开 App 首先看到。
2. 课表：查看日程、排课、调课。
3. 学员：学员搜索、详情、请假、联系家长。
4. 错题本：拍照上传错题，AI 解析。
5. 我的：个人、机构、设置、更多管理工具。

底部 Tab 使用线性图标 + 文字。选中态使用 `#018d71`，未选中使用灰色。不要在 Tab 上堆叠过多红点，只允许今日待办和错题分析结果出现轻量角标。

## 通用导航规则

- 一级 Tab 页顶部显示页面标题、日期或校区切换、一个轻量图标按钮。
- 二级页面左上角返回，右侧放更多或保存。
- 新增、筛选、选择老师/教室/班级、冲突处理优先使用底部弹层。
- 复杂表单采用分步流程，不要一次塞满整页。
- 页面必须保留空状态、加载状态、异常提示。

## 通用组件

- 今日课程卡片：课程名、时间、班级/学员、老师、教室、点名状态、主操作按钮。
- 状态标签：未开始、待点名、已点名、已完成、请假、缺勤、冲突、待分析、已解析。
- 快捷动作：图标 + 短文字，最多 4 个一排。
- 日期条：横向滚动 7 天，选中日期用绿色底。
- 分段控制器：日 / 周 / 月 / 列表，或 单次 / 规则 / 日历。
- 底部弹层：用于筛选、选择、确认、冲突处理。
- 空状态：简洁图标 + 一句话 + 一个主按钮。

## 不要生成的内容

- 不要生成 PC 后台风格的左侧菜单、顶部面包屑和大表格。
- 不要把排课做成 FullCalendar 密集月视图，移动端用日期条、列表、周视图卡片替代。
- 不要使用紫蓝渐变、米黄色、深蓝后台风、橙棕咖啡色作为主视觉。
- 不要做营销介绍页。
- 不要用大面积插画遮挡核心功能。
- 不要把每个功能都做成独立大卡片堆叠，信息要紧凑、可扫视。
