错题详情

description 题目文本

已知在平面直角坐标系中，抛物线 $y = ax^2 + bx + c$ 与 $x$ 轴交于 $A(-1, 0)$ 和 $B(3, 0)$ 两点，且过点 $C(0, -3)$。求该抛物线的解析式并确定其顶点坐标。

verified 标准答案

$y = x^2 - 2x - 3$，顶点坐标 $(1, -4)$

format_list_numbered 解题步骤

1

因为抛物线交 $x$ 轴于 $A(-1, 0), B(3, 0)$，可设交点式方程为 $y = a(x+1)(x-3)$。

2

将点 $C(0, -3)$ 代入方程，得 $-3 = a(0+1)(0-3)$，解得 $a = 1$。

3

展开方程得解析式为 $y = x^2 - 2x - 3$。配方得 $y = (x-1)^2 - 4$，因此顶点坐标为 $(1, -4)$。

error 错因分析

lightbulb

公式混淆
